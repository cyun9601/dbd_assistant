# 2026-10-06 DBD 데이터 갱신

정식 기준은 **10.1.2a**, 변경 예정 기준은 **10.2.0 PTB**에 **10.2.0 PTB→정식 개발자 업데이트(10월 5일)** 를 반영한 것입니다. 10.2.0 정식 패치노트는 아직 Steam·위키에 게시되지 않았고(위키 출시일 표 TBA), 개발자 업데이트가 "내일 전체 패치노트 공개"를 예고한 상태입니다. 그래서 `upcoming_date: null`을 유지하고 PTB 효과를 현재 효과로 전환하지 않습니다.

Steam 최근 공지 60개를 다시 수집했으며 10.1.2a 이후 새 패치노트는 없습니다. 개발자 업데이트는 버전별 패치노트가 아니므로 `patchnotes.json`에는 넣지 않고(넣으면 10.2.0이 정식 출시된 것으로 집계됨) 예정 데이터의 출처 링크로만 남깁니다.

## 개발자 업데이트로 확정된 PTB→정식 변경

| 진영 | 퍽 | 변경 | 반영 |
|---|---|---|---|
| 생존자 | 부담 감당 | 사용 후 모든 생존자의 퍽이 비활성화되는 조건 삭제 | 예정본에서 해당 줄 삭제 |
| 생존자 | 이런 일이 일어나다니 | 기본 스킬체크 대성공 구역 30% 증가 삭제(성공 구역 150/175/200%만 유지) | 예정본에서 해당 줄 삭제 |
| 살인마 | 어둠의 오만함 | 기본 공격 회복 속도 증가가 적중한 공격에는 적용되지 않음(빗나가거나 막힌 공격만) | 예정본 문구 수정 |
| 생존자 | 빌려온 시간 | PTB 리워크 철회, 현재 라이브 효과 유지 | 예정본·업데이트 예정 표시 제거 |
| 생존자 | 기회의 창 | PTB 그대로 유지 | 변경 없음 |

변경된 세 퍽의 예정본에는 `pending.live_changes_url`로 개발자 업데이트 링크를 남기고, 앱의 변경 예정 설명 블록에서 "PTB → 정식 변경 사항 반영" 링크로 보여줍니다.

## 스크립트

- `update_en_from_wiki.py`에 **`PTB_LIVE_CHANGES`** 표를 추가했습니다. 공식 PTB 노트에서 뽑은 예정본(영어·한글)에 `drop`(줄 삭제)·`replace`(문구 치환)·`revert`(변경 철회)를 덧씌우므로, 스크립트를 다시 돌려도 한글 예정본이 PTB 원문으로 되돌아가지 않습니다. 패치가 정식으로 나가 `released`에 들어가면 표는 자동으로 무시됩니다.
- `revert` 퍽은 위키가 아직 PTB 기준 설명을 싣고 있으므로 영어 본문도 갱신하지 않고 라이브 설명을 유지합니다(로그 `REVERT`).

- 임베딩 multi / same-ko / same-en 재생성(321×384). 라이브 설명은 바뀌지 않아 벡터 내용은 동일합니다.
