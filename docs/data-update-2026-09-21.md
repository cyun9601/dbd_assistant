## 적용 범위

- 퍽 321개를 대조하고 이전 10.1.0 예정 데이터를 정식 설명으로 승격했습니다.
- 현재 한국어 설명 22개를 정리했습니다. 특히 불침번은 탈진 회복만 20/25/30%, 숨을 곳 없음은 발전기 기준 24미터, 억압된 동맹은 수리 40/35/30초입니다.
- 10.2.0 PTB 퍽 58개(살인마 27개·생존자 31개)의 전체 효과를 공식 공지에서 추출하고 한국어로 번역했습니다. 현재 효과는 본문, PTB 효과는 pending에 있습니다.
- 살인마 44명·애드온 880개를 재수집했습니다. 기존 한국어와 달라진 능력 설명 및 애드온 34개의 한국어 설명을 정리했습니다. 아이콘은 기존 파일을 유지했으며 누락은 없습니다.
- 심판의 광신 조종 시간은 10.1.2a의 0.6초를 적용했습니다. 유형지 구출 시 32미터 거리·1초 면역과 기사의 판자 우회·48미터 사냥 종료는 공식 공지로 보완했습니다.
- 위키 누락 보완 3건은 data_corrections.json에 원문 해시와 출처를 남겼습니다. 원문이 달라지면 스크립트가 재검토를 요구합니다.
- 임베딩 multi / same-ko / same-en을 321×384로 재생성했습니다.
